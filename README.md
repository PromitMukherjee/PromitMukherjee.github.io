# Promit Mukherjee — Research Portfolio

Personal research portfolio of **Promit Mukherjee**, AI / ML Researcher & Systems Builder exploring machine learning, computer vision, representation learning, algorithms, and memory-efficient systems.

Live Website: [https://PromitMukherjee.github.io](https://PromitMukherjee.github.io)

## Stack & Architecture

- **Framework**: Next.js 14 (App Router)
- **Styling**: Tailwind CSS
- **Deployment**: GitHub Pages (Static Export via GitHub Actions)
- **Primary Focus**: AI/ML Research, Medical Vision, Representation Stability, Computational Biology, Efficient Algorithms

## Research Dossiers

1. **Diabetic Retinopathy AI** — Self-Supervised Vision Representation Learning

3. **MatrixResearch v1** — Neural Matrix Representation & Latent Collapse Analysis
4. **Stable In-Place Merge** — O(1) Auxiliary Memory Algorithmic Bounds
